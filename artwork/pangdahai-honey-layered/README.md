# 胖大海蜂蜜横幅：重建分层 PSD

4500 × 1050 px，RGB / 8 位，762 ppi，15 × 3.5 cm。55 个独立内容像素图层、10 个中文分组。

- [下载 PSD](pangdahai_honey_layered.psd?raw=true)
- [下载完整素材包（PSD、透明 PNG、图层清单与说明）](pangdahai_honey_complete.zip?raw=true)
- [查看预览](pangdahai_honey_preview.png)

在 GitHub 文件页点击 **Download raw file（下载原始文件）** 或下载箭头。ZIP 下载后先解压，再用 Photoshop 打开 PSD，按 F7 查看图层；无需构建或运行代码。

画面采用棕金蜂蜜底色、独立六边形蜂巢装饰和平铺蜂蜜液，搭配胖大海果实、绿叶、蜂巢块及两只写实蜜蜂。每颗胖大海、每只蜜蜂、每片绿叶、每块蜂巢及每个装饰六边形分别放在透明像素图层，可独立移动、隐藏或缩放。

成品不含文字、营养表或 Logo，背景不含植物及果实线描，蜂蜜液为平铺造型。所有内容均为像素图层，未包含文字层或矢量路径。

本稿依据合成参考图生成素材并重建组装，不是原始设计源文件。造型、纹理、光影及局部位置与参考图存在差异，被遮挡部分通过补绘重建。762 ppi 为文件的打印尺寸设置，不代表素材全部拥有原生 4500 px 的摄影细节。
