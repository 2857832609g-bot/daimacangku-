# 圣诞热可可吧台分层 PSD

1536 × 1024 像素，RGB / 8 位，66 个独立像素图层。

- [下载 ZIP 压缩包](christmas-cocoa-scene-layered.zip)
- [下载 PSD](christmas-cocoa-scene-layered.psd)
- [查看效果预览](christmas-cocoa-scene-preview.png)

在 GitHub 文件页点击 **Download raw file（下载原始文件）** 或下载箭头。解压 ZIP 后，用 Photoshop 打开 PSD，按 F7 查看图层。每层可单独移动、显示或隐藏。

包含 14 个独立杯子、4 个配料碗、6 个杯子蛋糕，以及分开的玻璃罩、底盘、陈列组、标牌、餐具、托盘、花环、蝴蝶结等。饮料与杯顶装饰随各自杯子保留，散料随碗保留，罩内堆叠饼干按陈列组保留。ZIP 同时包含各物件透明 PNG、图层位置清单和中文使用说明。

受原始文件缺失限制，本稿依据聊天参考图进行生成重建与组装，局部造型、纹理、字体和位置存在差异。
