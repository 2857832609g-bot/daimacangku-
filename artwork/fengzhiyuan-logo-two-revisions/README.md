# 蜂芝源 Logo · 顶部仅皇冠 · 两款白底设计

沿用第一稿圆脸抱抱蜂的姿势与形状，保留手中灵芝；去掉框顶部灵芝，只保留皇冠。
两款均加入“蜂芝源”三字，搭配花朵、蜜滴、六边形蜂巢框，1254 × 1254像素白底PNG。
