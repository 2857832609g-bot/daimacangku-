已去掉全部文字、营养表格、品牌标识与日期信息，中央六边形为空白。原黄色净含量胶囊仅去掉字样，空白底色保留。

鲜石斛按用户实物参考替换为细棕绿色、有自然节位的茎条；干石斛改为橄榄绿色卷曲枫斗。3 根鲜茎、9 片前景叶片、6 颗干枫斗均为独立透明图层，不合并成一堆。两只蜜蜂、两块蜂巢和各装饰六边形也分别独立；蜜液、标签框、左右植物底纹和光带分层。

两只蜜蜂、两块蜂巢的原图素材和位置保持不变。除文字删除区域、石斛替换区域及衔接处必要补绘外，沿用原有构图与配色。文字原来覆盖的底纹、光带，以及原粗茎遮挡后的区域需要补画，因此这些修补处不是原始隐藏源素材的无损恢复。

在 GitHub 文件页点击 Download raw file（下载原始文件）或下载箭头。ZIP 下载后先解压，用 Photoshop 打开 PSD，按 F7 查看图层。无需构建或运行代码。

所有内容均为像素图层，无实时文字或矢量路径。植物底纹每侧作为一株装饰元素，液体与其细小水珠按同一蜜液效果保留。图层边缘及遮挡底层根据平面参考拆分和补绘，大幅移动后局部边缘可能需微调。
